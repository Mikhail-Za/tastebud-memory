# recipe-site

Fictional sample project file, shipped so `examples/projects/` exists on a fresh clone and the
`has_file` / `promote` destination paths resolve out of the box.

`recipe-site` is one of the codebook projects in `examples/codebook.json` (`has_file: true`). A
real project note would collect its durable context here: architecture decisions, open threads,
links to the daily logs where the work happened.
